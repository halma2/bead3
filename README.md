This is a one-player dual board-game, which is widely known as connect-4.
Connect Four is a classic two-player connection game played on a vertical 7-column, 6-row grid. 
Each player takes turns dropping colored discs (usually red and yellow) from the top into one of the columns. 
The discs fall straight down, occupying the lowest available space in the column. The objective is to be the first player to form a line of four of one's own discs. 
This line can be **horizontal, vertical, or diagonal**. Players must strategically block their opponent while also setting up their own winning line.
The game ends immediately when a player connects four discs. If the grid is completely filled without a winner, the game is a draw. The game emphasizes strategic thinking and forward planning.
